# UUID Auth Mod

一个为 Minecraft 1.20.4 Fabric 服务器设计的轻量级身份验证模组。

当你连接至服务器时，它会要求客户端证明自己拥有一个预共享的密钥（UUID）。无法通过验证的玩家会在登录阶段和进入游戏后各被检查一次，两次均失败则被踢出。即使对方手动安装了模组，只要密钥不匹配，也无法留在服务器中。它提供了一种简单而有效的白名单补充手段。

## ✨ 特性

- **客户端-服务端分离**：客户端模组和服务端模组分别独立，仅需在各自环境安装。
- **双重验证**：不仅在登录阶段进行挑战‑应答验证，进入游戏世界后还会执行第二次验证，防止某些外挂绕过登录检查。
- **挑战‑应答机制 (Challenge-Response)**：服务器发送随机挑战码，客户端使用本地密钥计算 SHA‑256 哈希后返回，网络中永不传输明文密钥。
- **超时踢出**：游戏内验证在 5 秒内未收到正确应答，即自动断开连接。
- **纯配置文件驱动**：第一次启动后自动在 `config/` 目录下生成 JSON 配置文件，只需填入密钥即可。
- **轻量无感**：仅消耗极少量系统资源，验证过程对游戏体验零影响。
